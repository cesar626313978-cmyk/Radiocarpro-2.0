Política de Privacidad y Tratamiento de Datos

Aplicación: MyRadio Pro 2.0 (Audio-Car)

Dominio Oficial: https://www.audio-car.es

Última actualización: 26 de septiembre de 2026

1. Acceso a Google Drive y Permisos Solicitados

MyRadio Pro 2.0 solicita acceso de lectura mediante la API de Google Drive (drive.readonly) con el único fin funcional de listar y reproducir los archivos de audio contenidos dentro de la carpeta designada por el usuario (/mimusica).

  • Descarga en el Cliente: Los archivos de audio se solicitan mediante peticiones HTTPS directas entre el navegador web del usuario y los endpoints oficiales de Google APIs utilizando cabeceras Bearer. Ningún archivo binario de audio transita ni se almacena en servidores intermedios ajenos a Google.
  • No Modificación: La aplicación carece de permisos para editar, renombrar, eliminar o subir archivos a la unidad del usuario.

2. Almacenamiento Local (IndexedDB y Cache)

Para garantizar una reproducción fluida en movilidad (evitando cortes en zonas sin cobertura o túneles), la aplicación utiliza almacenamiento local en el navegador del dispositivo (IndexedDB / RAM) bajo estrictas salvaguardas de memoria:

  • Los fragmentos de audio en memoria se gestionan como Blob URLs temporales (máximo 2 concurrentes) y se liberan de forma determinista mediante URL.revokeObjectURL().
  • La base de datos local puede ser vaciada por el usuario en cualquier momento desde la interfaz cerrando sesión.

3. Declaración de Cumplimiento de la Política de Datos de Usuario de Google

El uso y la transferencia que hace MyRadio Pro 2.0 a cualquier otra aplicación de la información recibida a través de las APIs de Google se apegará estrictamente a la Política de Datos de Usuario de los Servicios de las APIs de Google (Google API Services User Data Policy), incluidos los requisitos de Uso Limitado (Limited Use requirements).

4. Sincronización en la Nube (Firebase)

La sincronización multi-dispositivo y modo coche almacena de forma segura en Firebase Firestore únicamente el identificador anonimizado de usuario, el correo electrónico y la lista de emisoras de radio o carpetas favoritas configuradas. En ningún caso se solicitan contraseñas ni información de pago.

5. Revocación de Consentimiento

El usuario puede revocar el acceso de MyRadio Pro 2.0 en cualquier momento a través del panel oficial de seguridad de Google en:
https://myaccount.google.com/permissions.
